⚙️ Settings

WallVault already works with zero keys using open sources. Add a free Pexels and/or Unsplash key to unlock full-text search against millions of images at up to 4K+ original resolution. Keys are stored only in your browser (localStorage) and sent directly to the provider.
Offline sources
Gallery sites (browse + import)
These are beautiful gallery sites, but they block browsers from calling them directly (no CORS). Browse them in a new tab, then right-click any wallpaper → “Copy image address” and paste it into the box below — it becomes a WallVault wallpaper instantly.
wallhaven.cc — huge searchable collection hdqwalls.com hdwallpapers.in wallpaperscraft.com wallpaperhub.app alphacoders.com wallpaperflare.com wallpapers.com dharmx/walls ← works as a live source ✅ manjaro wallpapers ⇢ GitLab (no CORS)
Pinterest & direct links
Pinterest doesn't allow browsers to call its API, but its image files do work here: open a pin → right-click the image → “Copy image address” → paste below (one or many). Links are saved in your browser and appear at the top of the grid.
Free API keys (optional)
Get keys free: pexels.com/api · unsplash.com/developers
